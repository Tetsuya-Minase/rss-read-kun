Discord に投稿するダイジェストを JSON で出力してください。

# 出力ルール

## 1. カテゴリ分類
各記事を、次の7カテゴリのいずれか「ちょうど1つ」に分類してください。

- 🤖 AI・LLM: 生成AI、LLM、機械学習、AIエージェント、AI開発ツール
- 🌐 Web・フロントエンド: ブラウザ、JavaScript/TypeScript、UIフレームワーク、Web標準
- 🛠️ バックエンド・インフラ: サーバ、DB、クラウド、CI/CD、OS、ネットワーク、セキュリティ
- 📱 モバイル・デスクトップ: iOS/Android、Swift/Kotlin、デスクトップアプリ
- 🎮 ゲーム開発: ゲームエンジン、ゲームデザイン、グラフィックス
- 🧑‍💼 キャリア・組織: 働き方、チーム運営、採用、資格、学習
- 📚 その他: 上記のいずれにも当てはまらないもの

- 1つの記事を複数のカテゴリに入れてはいけません。
- 該当記事が0件のカテゴリは categories 配列に含めないでください。
- categories は記事数の多い順に並べてください。

## 2. ハイライト（highlights）
- 全記事の中から「最も読む価値が高い」と判断した記事を最大3件選び、価値の高い順に並べてください。
- 選定基準は、具体的な実践知見があること > 新規性があること > 話題性があること、の順です。
- ハイライトに選んだ記事は categories の articles に含めないでください（重複禁止）。

## 3. 要約（summary）の書き方 — 最重要
- summary には、記事本文（description）から読み取れる「具体的な事実」を必ず1つ以上含めてください。
  具体的な事実とは、固有名詞（技術名・製品名・バージョン）、数値、または記事の結論です。
- 次のような「タイトルの言い換え」は禁止です。
  - NG:「〜について解説します」「〜を紹介します」「〜を考察します」
  - NG: タイトルに含まれる単語を並べ替えただけの文
  - OK:「Broadcom BCM4360 を wl ドライバで動かす手順。kernel header の不足が原因だった」
- description から具体的な事実が読み取れない場合は、推測で補わず、読み取れる範囲の事実だけを書いてください。
- 文字数: highlights の summary は60〜100文字、categories の articles の summary は40文字以内。
- 常体（だ・である調）で書き、「です・ます」は使わないでください。

## 4. message
その日の記事全体の傾向を1文（40文字以内）で書いてください。
例: AIエージェント開発の実践知見が集中した1日。

## 5. total
入力された記事の総数を入れてください。

# 禁止事項
- 入力に存在しない記事を作り出さないでください。
- link は入力の値をそのまま使い、変形・短縮しないでください。
- title は入力の値をそのまま使ってください（省略記号での短縮も禁止）。
